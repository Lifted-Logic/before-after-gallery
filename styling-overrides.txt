LL Before & After Gallery — Theme Customization Guide
How to style and override the plugin to fit any site it is installed on


OVERVIEW

Everything in this plugin that controls appearance can be overridden from the active WordPress theme without touching the plugin files themselves. There are three layers to work with:

  1. Template overrides — replace full PHP templates by mirroring the plugin's file paths inside the theme
  2. CSS variable overrides — replace the plugin's color and style tokens with site-specific values
  3. PHP filter hooks — swap out specific pieces of HTML markup generated by the plugin


THE THEME OVERRIDE FOLDER

All overrides go inside a folder called ll-before-after at the root of the active theme (or child theme):

  your-theme/
  └── ll-before-after/
      ├── (template files go here)
      ├── partials/
      │   └── (partial files go here)
      └── css/
          └── (css override files go here)

The plugin checks this folder first. If it finds a matching file, it uses the theme version. If not, it falls back to the plugin's own file. No configuration or filter is needed to activate an override — creating the file is enough.


TEMPLATE FILES

These are the full-page templates. Override any of them by copying the plugin version into the theme override folder and modifying it.

  Plugin source location:
    templates/single-ll_before_after.php
    templates/archive-ll_before_after.php
    templates/archive-ll_before_after_categories.php

  Theme override location:
    your-theme/ll-before-after/single-ll_before_after.php
    your-theme/ll-before-after/archive-ll_before_after.php
    your-theme/ll-before-after/archive-ll_before_after_categories.php

  single-ll_before_after.php — the individual before/after post page (gallery + sidebar)
  archive-ll_before_after.php — the main before/after archive grid with filter sidebar
  archive-ll_before_after_categories.php — the category listing page (only active when the Taxonomy Archive toggle is on in settings)


PARTIAL FILES

Partials are smaller template fragments included within the full templates. Override them the same way — copy to the theme override folder under partials/.

  Plugin source location:
    templates/partials/archive-hero-banner.php
    templates/partials/categories-hero-banner.php
    templates/partials/post-card.php
    templates/partials/before-after-slider-post-card.php
    templates/partials/category-card.php
    templates/partials/filters.php
    templates/partials/fit-image.php

  Theme override location:
    your-theme/ll-before-after/partials/archive-hero-banner.php
    your-theme/ll-before-after/partials/categories-hero-banner.php
    your-theme/ll-before-after/partials/post-card.php
    your-theme/ll-before-after/partials/before-after-slider-post-card.php
    your-theme/ll-before-after/partials/category-card.php
    your-theme/ll-before-after/partials/filters.php
    your-theme/ll-before-after/partials/fit-image.php

  archive-hero-banner.php — hero banner at the top of the main archive page
  categories-hero-banner.php — hero banner on the category listing page
  post-card.php — the card rendered for each before/after in the archive grid and related posts slider
  before-after-slider-post-card.php — card used specifically inside the Before & After Slider component (styled independently from the archive card)
  category-card.php — card for each category shown on the category listing page
  filters.php — the filter sidebar (accordions, checkboxes, search input)
  fit-image.php — the image rendering partial; override with caution, it is used broadly

  Note: fit-image.php can technically be overridden but most partials included via bag_include_partial() (internal plugin helper) cannot. Only partials loaded via TemplateLoader::get() support theme override.


IMPORTANT — HERO BANNER AND ACF FIELDS

When archive-hero-banner.php is overridden, the plugin automatically hides the default hero banner ACF fields from the admin. This is intentional — if you are supplying a custom template, you likely want to register your own fields.

To add your own ACF fields to the archive page, use this filter in the theme's functions.php:

  add_filter( 'll_bag/before_after_archive_fields', function ( array $fields ): array {
      $fields[] = [
          'key'   => 'field_my_theme_archive_heading',
          'label' => 'Archive Heading',
          'name'  => 'my_theme_archive_heading',
          'type'  => 'text',
      ];
      return $fields;
  } );

The field group is created automatically on the correct page — no need to call acf_add_local_field_group() yourself.

To read these values in your template:
  $page_id = (int) get_field( 'll_bag_posts_page', 'option' );
  $heading = get_field( 'my_theme_archive_heading', $page_id );

To force the plugin's default hero banner fields to appear even when you have overridden the partial:
  add_filter( 'll_bag/hero_banner_fields_enabled', '__return_true' );


CSS OVERRIDES

The plugin loads two CSS files that control all color and style tokens. Either can be overridden by placing a replacement file at the correct path in the theme:

  Plugin source location:
    resources/css/primitives.css     (raw hex color values)
    resources/css/ba-colors.css      (semantic UI tokens referencing primitives)

  Theme override location:
    your-theme/ll-before-after/css/primitives.css
    your-theme/ll-before-after/css/ba-colors.css

These files must be overridden as complete replacements — partial overrides are not supported for these two files.

--- primitives.css ---

This file defines named color variables. The default set uses a specific palette. Replace all values to match the site's brand.

  :root {
    --hex-codes-gunmetal:   #1D2729FF;
    --hex-codes-charcoal:   #494949FF;
    --hex-codes-light-grey: #CCCCCCFF;
    --hex-codes-white:      #FFFFFFFF;
    --hex-codes-sand:       #FCF7EFFF;
    --hex-codes-moss:       #B8C2B1FF;
    --hex-codes-evergreen:  #073D3DFF;
    --hex-codes-dandelion:  #DDEC64FF;
    --hex-codes-sky:        #C9DEDCFF;
    --hex-codes-teal:       #5A7B78FF;
    --hex-codes-overlay:    #00000099;
    --hex-codes-scrim:      #000000CC;
  }

The variable names can be anything you want — they just need to match what ba-colors.css references.

--- ba-colors.css ---

This file maps semantic UI roles to color values (usually referencing primitives). This is where you control what color each part of the UI uses. Below is the full list of variables with what they control:

  --general-background              Page/section background color
  --general-heading                 Default heading text color
  --general-body                    Default body text color
  --overlays-dark                   Dark overlay color (used over images)

  --filter-accordions-text          Filter sidebar accordion label text
  --filter-accordions-text-hover    Filter sidebar accordion label text on hover
  --filter-accordions-search-text   Text inside the filter search input
  --filter-accordions-search-fill   Background of the filter search input
  --filter-accordions-stroke        Border/divider lines in the filter sidebar

  --checkbox-text                   Text label next to filter checkboxes
  --checkbox-outline                Border color of unchecked checkboxes
  --checkbox-outline-active         Border color of checked checkboxes
  --checkbox-fill                   Background of unchecked checkboxes
  --checkbox-fill-active            Background of checked checkboxes
  --checkbox-check                  Color of the checkmark icon

  --nsfw-text                       Text color in the sensitive content selector (blur/unblur toggle)
  --nsfw-text-selected              Text color when a sensitive option is selected
  --nsfw-stroke                     Border of sensitive content toggle options
  --nsfw-stroke-selected            Border of selected sensitive content toggle option
  --nsfw-fill                       Background of sensitive content toggle option
  --nsfw-fill-selected              Background of selected sensitive content toggle option
  --nsfw-radius                     Border radius of sensitive content toggle options

  --ui-tags-fill                    Background of active filter tag pills
  --ui-tags-elements                Text/icon color inside active filter tag pills
  --ui-tags-radius                  Border radius of active filter tag pills

  --overlays-elements               Color of text/icons placed on top of dark overlays

  --cards-radius                    Border radius of before/after post cards
  --cards-background                Background color of post cards (also set via the admin color picker)

  --popup-scrim                     Background scrim/overlay behind modal popups
  --popup-fill                      Background fill of modal popup panels
  --popup-heading                   Heading text color inside modals
  --popup-ui                        UI element color inside modals (icons, close button)

  --treatment-tags-fill             Background of treatment/taxonomy tag pills on cards
  --treatment-tags-fill-hover       Background of treatment tag pills on hover
  --treatment-tags-text             Text color of treatment tag pills
  --treatment-tags-text-hover       Text color of treatment tag pills on hover
  --treatment-tags-radius           Border radius of treatment tag pills

  --detail-tabs-text                Text color of detail tabs (on single post page)
  --detail-tabs-text-hover          Text color of detail tabs on hover
  --detail-tabs-text-active         Text color of the active detail tab
  --detail-tabs-stroke              Border/underline of detail tabs
  --detail-tabs-stroke-hover        Border/underline of detail tabs on hover
  --detail-tabs-stroke-active       Border/underline of the active detail tab

  --cta-card-background             Background of the CTA card in the single post sidebar
  --cta-card-heading                Text color of the CTA card heading
  --cta-card-radius                 Border radius of the CTA card

  --video-ui-fill                   Background fill of video play button UI
  --video-ui-fill-hover             Background fill of video play button UI on hover
  --video-ui-element                Icon/element color inside video play button
  --video-ui-element-hover          Icon/element color inside video play button on hover

  --additional-images-active        Active indicator color for the additional images tab row
  --additional-images-chevron       Chevron/arrow color for the additional images row
  --additional-images-chevron-hover Chevron/arrow color on hover

Note: The card background color can also be set via the admin UI at B&A Posts > Settings > Card Background Color. That admin setting outputs an inline CSS variable (--ll-ba-card-bg) that overrides the --cards-background value from ba-colors.css.


HEADER AND FOOTER FILTERS

By default the archive templates call get_header() and get_footer(). Use these filters to swap the template name or skip them entirely.

Load a named variant (calls get_header('minimal') which loads header-minimal.php):
  add_filter( 'll_bag/header_template', fn() => 'minimal' );
  add_filter( 'll_bag/footer_template', fn() => 'minimal' );

Skip header and/or footer completely:
  add_filter( 'll_bag/header_template', fn() => false );
  add_filter( 'll_bag/footer_template', fn() => false );

Returning an empty string (the default) calls get_header() with no argument, which is standard WordPress behavior.


PHP FILTER HOOKS FOR MARKUP

For small changes — button labels, icon SVGs, CSS classes — the plugin exposes WordPress filters that let you swap specific HTML fragments without overriding a full template. All filters go in the theme's functions.php.


--- lifted_logic/bag/bag_back_button_markup ---

Overrides the back-to-gallery link at the top of the single post sidebar.

Parameters: $markup (string), $classes (string), $text (string), $href (string)

  add_filter( 'lifted_logic/bag/bag_back_button_markup', function( $markup, $classes, $text, $href ) {
      return '<a href="' . $href . '" class="' . $classes . '">' . $text . '</a>';
  }, 10, 4 );

The $href automatically uses the ba_ref query param when the visitor came from the gallery page (preserving any active filter state), and falls back to the plain archive URL otherwise.


--- lifted_logic/bag/related_slider_arrows_markup ---

Overrides the previous/next arrow buttons on the related posts slider. Buttons must keep splide__arrow--prev and splide__arrow--next classes — Splide.js uses these for navigation.

Parameters: $markup (string), $prev (string), $next (string)

  add_filter( 'lifted_logic/bag/related_slider_arrows_markup', function( $markup, $prev, $next ) {
      return '<div class="ll-ba-single__related-arrows splide__arrows">' . $prev . $next . '</div>';
  }, 10, 3 );


--- lifted_logic/bag/link_card_markup ---

Overrides the CTA card in the single post sidebar. Only renders when a CTA link is configured in B&A Posts > Settings > Single Page tab.

Parameters: $markup (string), $title (string), $link (array with keys: url, title, target)

  add_filter( 'lifted_logic/bag/link_card_markup', function( $markup, $title, $link ) {
      $href = esc_url( $link['url'] ?? '' );
      $text = esc_html( $link['title'] ?? '' );
      return '<div class="ll-ba-single__cta-card"><p>' . $title . '</p><a href="' . $href . '">' . $text . '</a></div>';
  }, 10, 3 );


--- lifted_logic/bag/nsfw_modal_markup ---

Overrides the sensitive content confirmation modal. The modal element must keep id="ll-ba-nsfw-modal" and the class ll-ba-hidden — JavaScript finds and shows it by id. Buttons are wired via data-nsfw-action attributes: unblur-once, unblur-all, and leave. The close button also needs data-fallback-url for visits with no referrer.

Parameters: $markup (string), $message (string), $archive_url (string), $actions (string)

The $actions string is passed separately so you can replace just the buttons using str_replace:

  add_filter( 'lifted_logic/bag/nsfw_modal_markup', function( $markup, $message, $archive_url, $actions ) {
      $custom_actions = '
        <div class="ll-ba-nsfw-modal__actions">
          <button type="button" class="ba_btn-primary" data-nsfw-action="unblur-all">Show Sensitive Content</button>
        </div>
      ';
      return str_replace( $actions, $custom_actions, $markup );
  }, 10, 4 );


--- lifted_logic/bag/filter_actions_markup ---

Overrides the Clear / Apply button bar at the bottom of the mobile filter flyout (only visible on viewports narrower than 768px). The Clear button must keep id="ll-ba-filter-clear-mobile" and the Apply button must keep id="ll-ba-filter-apply".

Parameters: $markup (string)

  add_filter( 'lifted_logic/bag/filter_actions_markup', function( $markup ) {
      return '
        <div class="ll-ba-filter-actions">
          <button type="button" id="ll-ba-filter-clear-mobile">Reset</button>
          <button type="button" id="ll-ba-filter-apply">Show Results</button>
        </div>
      ';
  } );


--- lifted_logic/bag/slider_card_sensitive_overlay_markup ---

Overrides the sensitive content overlay panel on slider cards (used in the Before & After Slider component). Buttons are wired via data-slider-card-action: unblur-once (removes blur on this card only) and unblur-all (removes blur everywhere and saves cookie).

Parameters: $markup (string), $message (string), $actions (string)

  add_filter( 'lifted_logic/bag/slider_card_sensitive_overlay_markup', function( $markup, $message, $actions ) {
      $custom_actions = '
        <div class="ll-ba-slider-card__sensitive-actions">
          <button type="button" data-slider-card-action="unblur-all">Show Content</button>
        </div>
      ';
      return str_replace( $actions, $custom_actions, $markup );
  }, 10, 3 );


--- lifted_logic/bag/single_sidebar_classes ---

Injects additional CSS classes onto the sidebar element on the single post page.

Parameters: $classes (array)

  add_filter( 'lifted_logic/bag/single_sidebar_classes', function ( $classes ) {
      $classes[] = 'my-custom-sidebar-class';
      return $classes;
  } );


--- lifted_logic/bag/archive_inner_classes ---

Injects additional CSS classes onto the archive inner wrapper.

Parameters: $classes (array)

  add_filter( 'lifted_logic/bag/archive_inner_classes', function ( $classes ) {
      $classes[] = 'has-sidebar';
      return $classes;
  } );


--- lifted_logic/bag/grid_classes ---

Injects additional CSS classes onto the Before & Afters Grid component wrapper.

Parameters: $classes (array)

  add_filter( 'lifted_logic/bag/grid_classes', function ( $classes ) {
      $classes[] = 'theme-two';
      return $classes;
  } );


DISABLING PLUGIN COMPONENTS

The plugin injects three flexible content components into the LL theme's component picker:
  - Related Before & Afters
  - Before & Afters Grid
  - Before & After Slider

To disable all three at once, add this to the theme's functions.php:
  add_filter( 'll_bag/register_components', '__return_false' );

To disable them individually:
  add_filter( 'll_bag/register_component/ll_ba_related_bna', '__return_false' );
  add_filter( 'll_bag/register_component/ll_ba_grid',        '__return_false' );
  add_filter( 'll_bag/register_component/ll_ba_slider',      '__return_false' );

These filters must be in functions.php (not added later) so they run before the plugin checks them on after_setup_theme.


QUICK REFERENCE — WHAT TO OVERRIDE FOR COMMON TASKS

Change all colors to match the site brand:
  Override your-theme/ll-before-after/css/primitives.css and ba-colors.css

Change card background color:
  Use the admin UI at B&A Posts > Settings > Card Background Color, or override --cards-background in ba-colors.css

Change button styles:
  The plugin uses two button classes: ba_btn-primary and ba_btn-secondary. These are defined in the plugin's CSS. Override by targeting these classes in the theme's own stylesheet (they will cascade as long as specificity matches or exceeds the plugin's rules), or override the template/partial that uses them to swap in theme button classes instead.

Change typography (heading sizes, font weights):
  The plugin uses ba_hdg-medium and ba_hdg-small for internal headings. Override by targeting these classes in the theme stylesheet, or copy the relevant template partial and replace the class names with the site's typography classes.

Change the layout or structure of a card:
  Override your-theme/ll-before-after/partials/post-card.php

Change the hero banner:
  Override your-theme/ll-before-after/partials/archive-hero-banner.php and register custom ACF fields via the ll_bag/before_after_archive_fields filter

Change the filter sidebar layout:
  Override your-theme/ll-before-after/partials/filters.php

Change the NSFW modal message text:
  Edit it directly in the admin at B&A Posts > Settings > NSFW Popup tab. No code change needed.

Change the NSFW modal button labels:
  Use the lifted_logic/bag/nsfw_modal_markup filter

Change the "Back to Gallery" link text or styling:
  Use the lifted_logic/bag/bag_back_button_markup filter
